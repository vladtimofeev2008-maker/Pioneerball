# 🚁 Дрон-пионербол: панель судьи

Веб-приложение для судейства соревнований по дрон-пионерболу. Таймер, счёт, история раундов и турнирная сетка работают в одном окне браузера, в том числе на телефоне.

Без установки, без серверов, без зависимостей: всё приложение лежит в одном HTML-файле.

## ✨ Возможности

- **Выбор стороны.** Судья выбирает, какую команду (синих или красных) он судит, и видит только её счёт.
- **Таймер и секундомер.** Пресеты 1:00, 2:00, 3:00, кнопки ±10 секунд и своё время. У секундомера есть миллисекундное кольцо.
- **Обратный отсчёт 3 · 2 · 1 · Arm** перед стартом таймера.
- **Счёт по тапу.** Касание по карточке команды засчитывает гол, кнопка «−1 гол» исправляет ошибку. После конца времени счёт блокируется.
- **Защита от случайных сбросов.** Счёт сбрасывается только удержанием кнопки около секунды.
- **История раундов.** Раунд записывается автоматически, когда таймер доходит до нуля. Матчи можно раскладывать по папкам соревнований и смотреть статистику побед и ничьих.
- **Режим «Турнир».**
  - сетка на 2–32 команды с жеребьёвкой;
  - матч за 3 место и пьедестал;
  - если команд меньше, чем мест в сетке, часть команд проходит дальше без игры;
  - сетку можно посмотреть схемой и скачать картинкой;
  - редактирование результатов и команд защищено паролем.
- **Три звуковые схемы** (Бас, Синт, Классика) и вибрация на гол, отсчёт и конец раунда.
- **Темы оформления:** светлая, тёмная, системная. Анимации можно отключить.
- **Экран не гаснет** во время матча (Wake Lock, если браузер поддерживает).
- **Подсказка про энергосбережение.** Если телефон работает в режиме энергосбережения и анимации замедляются, приложение предложит его отключить.

## 🚀 Запуск

**Локально.** Скачайте файл `index.html` и откройте его в браузере.

**GitHub Pages.**
1. Переименуйте HTML-файл в `index.html` и загрузите его в корень репозитория.
2. Откройте Settings → Pages.
3. В разделе Source выберите ветку `main` и папку `/ (root)`.
4. Через минуту сайт станет доступен по адресу `https://<ваш-аккаунт>.github.io/<репозиторий>/`.

## 📱 Как пользоваться

1. Откройте страницу и выберите команду, которую судите.
2. Нажмите «Старт». После отсчёта пойдёт таймер.
3. Тапайте по цвету команды при каждом голе.
4. Когда время выйдет, раунд сам запишется в историю (🏆).
5. Для турнира нажмите «🏁 Турнир», добавьте команды и выберите матч, который будете судить.

## 🔐 Пароль турнира

Пароль режима редактирования сетки по умолчанию: `1111`. Сменить его можно в настройках (⚙️), для этого нужен старый пароль.

Пароль хранится в браузере в виде хеша. Это защита от случайных правок, а не криптографическая защита.

## 💾 Хранение данных

Счёт, история, папки соревнований, турнир и настройки сохраняются в `localStorage` браузера. Данные не отправляются на сервер и не синхронизируются между устройствами. Если очистить данные сайта в браузере, всё пропадёт.

## 🛠 Технологии

- HTML, CSS и JavaScript без фреймворков и сборщиков
- Web Audio API для звуков
- Vibration API и Screen Wake Lock API
- Canvas для картинки турнирной сетки
- Шрифты Rubik и Unbounded через Google Fonts
